## File Types

### STEP (.stp)

3D CAD files that can be used for personal 3D printing, modification, and customization.

STEP files can be opened with compatible CAD software such as:

- FreeCAD
- Fusion 360
- SolidWorks
- Onshape

### Six-view Drawing (.pdf)

Technical drawings showing the wrist rest from multiple orthographic views for dimensional and design reference.
